## درباره‌ی ما

گروه آرشیو از سال ۱۳۸۰ در یزد فعالیت می‌کند. کار ما طراحی و ساخت محصولات دیجیتال است: از وب‌سایت شرکتی و فروشگاهی تا پنل‌های مدیریتی، سامانه‌های مالی و صرافی، و اپلیکیشن‌های تلگرامی.

### خدمات

- طراحی و توسعه‌ی وب‌سایت (شرکتی، فروشگاهی، لندینگ)
- سامانه‌های تحت وب و پنل مدیریت
- راه‌اندازی صرافی و پلتفرم‌های ارز دیجیتال
- اپلیکیشن و Telegram Web App
- برندینگ و طراحی گرافیک
